# Al-Qur'an (version web)

Lecture du Coran en mushaf classique, installable sur iPhone (Safari › Partager › « Sur l'écran d'accueil »).

- Texte du Coran (Uthmani) : projet Tanzil (tanzil.net), texte non modifié.
- Traduction française : M. Hamidullah, via Tanzil.
- Police : Amiri Quran (licence libre OFL).
- Aucune donnée n'est envoyée : tout reste sur l'appareil.
